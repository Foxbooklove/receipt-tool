# 과제 7단계 충족 내역

각 단계를 무엇으로 충족했는지, 증빙 화면을 어디서 볼 수 있는지 정리했다.

---

## 1단계 · 환경 설치

| 항목 | 내용 |
|---|---|
| 개발 도구 | Node.js 24, Claude Code (CLI) |
| AI 모델 실행 | Ollama + Qwen2.5-VL 7B (6.0GB) |
| 실행 하드웨어 | Windows, RTX 4070 Ti (VRAM 12GB) |

**증빙 화면**: 터미널에서 `ollama list` 실행 → 모델 목록에 `qwen2.5vl:7b`가 보이는 화면.

---

## 2단계 · 서비스 개발

React + TypeScript 단일 화면 웹앱. 업로드 → 파싱 → 검토 표 → 엑셀 다운로드가 한 화면에서 끝난다.

| 파일 | 역할 |
|---|---|
| `src/App.tsx` | 전체 화면과 상태 관리 |
| `src/parse.ts` | AI 모델 호출과 프롬프트 |
| `src/excel.ts` | 엑셀 파일 생성 |
| `src/supabase.ts` | DB 저장, 이미지 업로드, 지표 기록 |

**증빙 화면**: 영수증을 올려 표가 채워지는 과정 전체.

---

## 3단계 · 디자인

색상·간격·타이포를 토큰으로 정의하고 다크모드를 대응했다. 한글 가독성을 위해 Pretendard 폰트를 적용했다.

- 드래그앤드롭 업로드
- 진행률 바 (`12 / 15장 · 80%`)
- 요약 카드 4개 (건수 / 합계 금액 / 소요 시간 / 장당 평균)
- 표: 헤더·합계 행 고정, 원본 영수증 썸네일

**증빙 화면**: 첫 화면 전체. 다크모드 전환을 함께 보여주면 더 좋다.

---

## 4단계 · 배포

**https://receipt-tool-rho.vercel.app**

Vercel에 정적 빌드로 배포했다. GitHub `main` 브랜치에 푸시하면 자동으로 다시 배포된다.

**증빙 화면**: 위 주소 접속 화면, Vercel 대시보드의 `Ready` 상태.

> 주의: Vercel이 배포마다 만드는 임시 주소(`receipt-tool-597hdt3h2-...`)가 아니라 위 고정 주소를 쓴다.

---

## 5단계 · DB 관리

Supabase (PostgreSQL + Storage) 를 연동했다.

| 테이블 / 버킷 | 용도 | 현재 데이터 |
|---|---|---|
| `receipts` | 정리된 영수증 항목 | 15건 (합계 237,430원) |
| `parse_metrics` | 처리 건수·소요 시간 | 4회 실행 기록 |
| Storage `receipts` | 영수증 원본 이미지 | 15장 |

접속 정보는 Vercel 환경변수로 주입한다 (과제 지침에 명시된 방식).

**증빙 화면**: Supabase 대시보드 → Table Editor → `receipts` 테이블에 행이 쌓여 있는 화면. Storage 버킷의 이미지 목록.

---

## 6단계 · 데이터 측정

두 갈래로 측정한다.

**가. Google Analytics 4** (`G-YSKQ76ZBLZ`) — 방문자 수, 페이지뷰 등 웹 트래픽

**나. 자체 지표 테이블** (`parse_metrics`) — 처리 건수와 소요 시간

GA만으로는 "영수증 한 장을 처리하는 데 몇 초가 걸렸는지"를 잴 수 없어서 별도 테이블을 두었다. 이 값은 화면의 요약 카드로도 바로 보여준다. **측정한 값을 사용자에게 되돌려주는 구조**라는 점을 설명하면 좋다.

**증빙 화면**: GA `보고서 → 실시간`에서 접속자가 잡히는 화면, 그리고 앱 화면의 요약 카드.

---

## 7단계 · 검색 등록

Google Search Console에 등록했다.

| 항목 | 상태 |
|---|---|
| 소유권 확인 | 완료 (Google 애널리틱스 방식으로 자동 확인) |
| 사이트맵 제출 | `sitemap.xml` 제출 완료 |
| 색인 요청 | 제출 완료 |

`public/robots.txt`와 `public/sitemap.xml`을 두었고, `index.html`에 `title`, `description`, `canonical`을 넣었다.

**증빙 화면**: "소유권이 자동으로 확인됨" 화면, 사이트맵 제출 목록, 색인 생성 요청 화면.

> 새로 만든 사이트가 실제 검색 결과에 나오기까지는 며칠에서 몇 주가 걸린다. 과제는 등록 절차를 밟은 것으로 충족되며, 검색 노출을 기다릴 필요는 없다.

---

## 주의: 지우면 안 되는 것

`index.html`의 Google Analytics 스크립트는 **6단계와 7단계를 동시에 담당한다.** Search Console 소유권을 이 스크립트로 확인받았기 때문에, 지우면 7단계 등록이 풀린다.
